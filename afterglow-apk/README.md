# AfterGlow+
1. Create a new GitHub repo and upload everything in this folder (keep the `.github` folder).
2. Open the repo's **Actions** tab, run **Build APK** (it also runs on every push to main).
3. When it finishes, open the run and download **AfterGlow-APK** from Artifacts. Unzip it and install `app-debug.apk` on your phone (allow installs from unknown sources).
4. The message checker works offline for free. To use AI instead, add an API key in Settings > AI analysis.
The app icon comes from `assets/icon-only.png`, `icon-foreground.png` and `icon-background.png`.
